## 🇪🇸 Español

La primera versión de **Shinobi.pdf** (antes *PDF Splitter Pro*): una reescritura completa con interfaz nueva y muchas más herramientas. Todo se procesa en tu computadora; tus archivos nunca salen de ella.

### ⬇️ Descarga
- **`ShinobiPDF-Setup.exe`**: instalador (recomendado). No pide permisos de administrador y te deja elegir el idioma.
- **`ShinobiPDF-Portable.zip`**: sin instalación; descomprimí y abrí `Shinobi.exe`.

Requiere Windows 10 u 11 de 64 bits.

### ✨ Novedades
- **Cinco formas de dividir:** por capítulos, cada N páginas, por rangos (`1-3, 5, 8-`), por tamaño máximo (ideal para mail) o **por texto**, por ejemplo un archivo por cada «Factura N°».
- **Detección automática de capítulos** desde el índice del PDF.
- **Visor con miniaturas de colores**, búsqueda de texto (Ctrl+F), rotar y excluir páginas.
- **Marcado desde el visor:** "Usar como inicio" y "Usar como fin" mientras recorrés el PDF.
- **Unir PDFs**, **exportar páginas a imágenes** y **procesar en lote**.
- **PDFs con contraseña**, arrastrar y soltar, y clic derecho → "Dividir con Shinobi.pdf" en el Explorador.
- **Español e inglés**, modo claro y oscuro, y una interfaz que se adapta a notebooks y al zoom de Windows.
- **Plantillas** para reutilizar configuraciones, y aviso automático de nuevas versiones.

### ⚠️ Aviso de Windows
Por ahora el instalador no tiene firma digital, así que Windows puede mostrar *"Windows protegió su PC"*. Para continuar tocá **Más información → Ejecutar de todas formas**. El código es abierto y el instalador se compila automáticamente desde este repositorio.

¿Encontraste un problema? Usá **Ajustes → Reportar un problema** dentro de la app, o abrí un [issue](https://github.com/MarraTX/ShinobiPDF/issues).

## 🇬🇧 English

The first release of **Shinobi.pdf** (formerly *PDF Splitter Pro*): a complete rewrite with a new interface and many more tools. Everything runs on your computer; your files never leave it.

### ⬇️ Download
- **`ShinobiPDF-Setup.exe`**: installer (recommended). No admin rights needed, and you can pick your language.
- **`ShinobiPDF-Portable.zip`**: no installation; unzip and run `Shinobi.exe`.

Requires 64-bit Windows 10 or 11.

### ✨ What's new
- **Five ways to split:** by chapters, every N pages, by ranges (`1-3, 5, 8-`), by maximum size (great for email) or **by text**, e.g. one file per "Invoice No.".
- **Automatic chapter detection** from the PDF's outline.
- **Viewer with color-coded thumbnails**, text search (Ctrl+F), rotate and exclude pages.
- **Mark pages from the viewer:** "Use as start" and "Use as end" while browsing the PDF.
- **Merge PDFs**, **export pages to images** and **batch processing**.
- **Password-protected PDFs**, drag and drop, and right-click → "Split with Shinobi.pdf" in File Explorer.
- **English and Spanish**, light and dark mode, and a layout that adapts to laptops and Windows scaling.
- **Templates** to reuse settings, and automatic update notifications.

### ⚠️ Windows warning
The installer isn't digitally signed yet, so Windows may show *"Windows protected your PC"*. To continue, click **More info → Run anyway**. The code is open source and the installer is built automatically from this repository.

Found a problem? Use **Settings → Report a problem** inside the app, or open an [issue](https://github.com/MarraTX/ShinobiPDF/issues).
